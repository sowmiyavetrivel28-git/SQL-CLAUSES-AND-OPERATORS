# SQL-CLAUSES-AND-OPERATORS 

## Project Title
 Clauses & Operators

## Objective
To practice SQL clauses and operators by writing queries for data retrieval, filtering, comparison, arithmetic calculations, logical conditions, NULL handling, range checks, and pattern matching.

## Database Used
ECommerceDB

## Topics Covered
- DISTINCT and AS
- WHERE Clause
- Comparison Operators
- Arithmetic Operators
- Logical Operators
- IS NULL / IS NOT NULL
- IN / NOT IN
- BETWEEN / NOT BETWEEN
- LIKE / NOT LIKE
- Mixed Conditions

## Learning Outcomes
- Understand how to retrieve unique records.
- Learn to filter data using WHERE conditions.
- Apply comparison and logical operators effectively.
- Handle NULL values in queries.
- Use IN, BETWEEN, and LIKE operators for advanced filtering.
- Combine multiple conditions to solve real-world SQL problems.
